{% translate "What is Panchang?" %}

{% blocktranslate trimmed %} Panchang is the Hindu calendar and almanac, kept in the traditional units of Indian timekeeping. The word comes from the Sanskrit "pancha" (five) and "anga" (limbs): the five limbs of the day. {% endblocktranslate %}

{% translate "The five limbs of the Panchang" %}

  • {% translate "Tithi" %}: {% translate "Lunar day (30 tithis in a lunar month)" %}
  • {% translate "Nakshatra" %}: {% translate "The Moon's star (27 nakshatras in the zodiac)" %}
  • {% translate "Yoga" %}: {% translate "Formed by the Sun's and Moon's positions together (27 yogas)" %}
  • {% translate "Karana" %}: {% translate "Half of a tithi (11 karanas repeated through the month)" %}
  • {% translate "Vaar" %}: {% translate "Day of the week, from sunrise to sunrise" %}

{% translate "In daily life" %}

{% blocktranslate trimmed %} The panchang fixes the dates of festivals and vrats, and the auspicious times (muhurat) for weddings, griha pravesh, new ventures and puja. It tells you which part of the day is good for what. {% endblocktranslate %}
